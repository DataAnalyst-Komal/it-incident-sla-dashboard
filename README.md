# IT Incident & SLA Performance Dashboard

## Overview
This project analyzes IT incident data and SLA performance to identify operational inefficiencies and improvement opportunities.

## Objective
To understand incident patterns, identify root causes, and evaluate SLA performance across departments, priorities, and locations.

## Tech Stack
- Power BI  
- Power Query (Data Cleaning & Transformation)  
- DAX (Calculated Columns & Measures)  

## Dataset
The dataset contains IT incident records including priority, category, department, resolution time, and SLA status.

## Key Insights
- High SLA breach (**72.75%**) indicates significant performance gaps in incident resolution  
- **IT Support** handles the highest volume of incidents (**268**) and shows the highest SLA breach (**74.63%**)  
- **Security** and **Server-related** issues contribute heavily to High (**324**) and Critical (**320**) priority incidents.  
- High and Critical priority incidents require the longest resolution time (**~35 hrs**), increasing SLA breach risk.
- - SLA breaches peak during **October–November**, indicating operational strain  
- **Remote Site 1** reports the highest number of incidents (**276**)  

## Dashboard Features
- SLA compliance tracking  
- Incident trend analysis over time  
- Priority-wise breakdown of incidents  
- Department-wise performance comparison  
- Root cause analysis of incidents  

## Business Impact
- Identifies bottlenecks in incident resolution  
- Supports prioritization of high-risk incident categories  
- Improves visibility into SLA performance across teams  
- Enables better resource allocation for IT support
